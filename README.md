# RAG Foundations

This repository contains a structured, end-to-end learning path for Retrieval-Augmented Generation (RAG), from core concepts to production-ready architecture patterns.

## Document Roadmap

- `1-Foundations.md` - Core RAG concepts, key components, and why RAG matters.
- `2-Data-Ingestion-and-Preprocessing.md` - Data pipelines, cleaning, normalization, and preparation for indexing.
- `3-Chunking-Strategies.md` - Chunking approaches, trade-offs, and best practices for retrieval quality.
- `4-Embeddings.md` - Embedding fundamentals, model choices, and vector representation considerations.
- `5-Vector-Databases.md` - Vector store concepts, indexing strategies, and practical database selection criteria.
- `6-Retrieval-Techniques.md` - Retrieval methods (dense/sparse/hybrid) and query-time optimization techniques.
- `7-Re-ranking.md` - Re-ranking fundamentals and methods to improve top-k result relevance.
- `8-Generation-Layer.md` - Prompting and generation workflows that use retrieved context effectively.
- `9-Evaluation.md` - Offline/online evaluation, quality metrics, and system benchmarking.
- `10-Advanced-RAG-Architectures.md` - Advanced system designs and multi-step retrieval-generation pipelines.
- `11-Types-of-RAG-Top-4.md` - A concise breakdown of the top RAG variants and when to use each.
- `12-Performance-Scaling.md` - Latency, throughput, caching, and scaling strategies for larger workloads.
- `13-Security-Privacy.md` - Security controls, privacy considerations, and safe data handling in RAG systems.
- `14-Production-System-Design.md` - Reliability, observability, deployment, and production engineering patterns.
- `15-Real-world-Problems-to-Practice.md` - Practical problem sets and scenarios for hands-on learning.
- `16-Emerging-RAG-Patterns.md` - New and evolving RAG trends, techniques, and future directions.
